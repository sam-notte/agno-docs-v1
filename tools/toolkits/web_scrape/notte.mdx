**NotteTools** enable an Agent to drive a remote browser session via [Notte](https://notte.cc), a managed browser infrastructure platform for AI agents. Notte exposes observe, act, scrape, and agent primitives over a single API key, so the toolkit needs no Playwright install.

## Prerequisites

The following example requires a Notte API key. Get one at the [Notte console](https://console.notte.cc).

```shell
pip install notte-sdk
export NOTTE_API_KEY=xxx
```


## Example

The following agent uses Notte to visit `https://quotes.toscrape.com` and extract content. Then navigate to page two of the website and get quotes from there as well.

```python cookbook/tools/notte_tools.py
from agno.agent import Agent
from agno.tools.notte import NotteTools

agent = Agent(
    name="Web Automation Assistant",
    tools=[NotteTools()],
    instructions=[
        "You are a web automation assistant powered by Notte. You can help with:",
        "1. Filling forms and clicking through multi-step web flows",
        "2. Extracting clean markdown or structured data from web pages",
        "3. Capturing screenshots of websites",
        "4. Monitoring website changes",
        "5. Delegating complex multi-step browsing to an autonomous browser agent when a task is too open-ended for step-by-step tool use",
        "Note: call observe before click or fill to discover the current interactive element IDs (B1, I1, L1, ...).",
    ],
    markdown=True,
)

agent.print_response("""
    Visit https://quotes.toscrape.com and:
    1. Extract the first 5 quotes and their authors
    2. Navigate to page 2
    3. Extract the first 5 quotes from page 2
""")
```

## Toolkit Params

| Parameter            | Type   | Default     | Description                                                                                                       |
| -------------------- | ------ | ----------- | ----------------------------------------------------------------------------------------------------------------- |
| `api_key`            | `str`  | `None`      | Notte API key. If not provided, uses NOTTE_API_KEY env var.                                                       |
| `server_url`         | `str`  | `None`      | Custom Notte API endpoint. Use only for self-hosted deployments or non-default regions. Defaults to `https://api.notte.cc`. |
| `headless`           | `bool` | `True`      | Run the remote browser headless.                                                                                  |
| `solve_captchas`     | `bool` | `False`     | Automatically solve captchas during the session.                                                                  |
| `proxies`            | `bool` | `False`     | Route the session through Notte's proxy pool.                                                                     |
| `browser_type`       | `str`  | `chromium`  | One of `chromium`, `chrome`, `firefox`.                                                                           |
| `perception_type`    | `str`  | `fast`      | `fast` or `deep`. Controls how aggressively Notte parses the DOM into an action space.                            |
| `reasoning_model`    | `str`  | `None`      | LLM identifier passed through to the Notte agent (e.g. `gemini/gemini-2.5-flash`). Used by `run_agent`.            |
| `max_agent_steps`    | `int`  | `15`        | Default step cap for `run_agent`.                                                                                 |
| `max_content_length` | `int`  | `100000`    | Truncate page content above this many characters. Set `None` for no limit.                                        |

## Toolkit Functions

| Function           | Description                                                                                                          |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| `navigate_to`      | Navigates the remote browser to a URL.                                                                               |
| `screenshot`       | Captures a screenshot of the current page and writes it to disk.                                                     |
| `get_page_content` | Returns the current page as clean markdown, truncated to `max_content_length`.                                       |
| `observe`          | Snapshots the current page and returns the action space (interactive element IDs the LLM can target).                |
| `click`            | Clicks an interactive element by its Notte ID (e.g. `B1`).                                                            |
| `fill`             | Fills an input element by its Notte ID with the provided value.                                                      |
| `scrape`           | Scrapes the page as markdown by default, or as structured data when natural-language instructions are provided.      |
| `run_agent`        | Hands a multi-step task to a Notte browser agent inside the same session and returns its final answer.               |
| `close_session`    | Stops the current session and releases remote browser resources.                                                     |
